# 隐私声明与数据处理说明（鲸鱼娘）

本文件是工程实现的一部分，不是可选文案。设置页会在用户首次授予通知使用权前后展示同样的要点。

## 1. 我们接触什么

| 数据 | 何时接触 | 是否离开设备 |
|---|---|---|
| 通知栏内容 | 用户授予“通知使用权”后，系统把**所有应用**的通知投递给 `QqNotificationListener` | 否（除非进入任务 prompt，见 §3） |
| 当前屏幕的无障碍节点树 | 每次执行任务时抓取 | 是：裁剪后的文字与控件位置会发给用户配置的 LLM |
| 屏幕截图 | 仅在用户开启“视觉模型”且 API 30+ 时 | 是：720px JPEG Base64 发给用户配置的 LLM |
| 用户与鲸鱼娘的对话 | 聊天/任务时 | 是：作为 conversation 发给用户配置的 LLM |
| 应用设置、API Key | 用户填写 | 否：Key 仅存本机 Keystore |
| 长期记忆（事实/任务摘要/聊天） | 自动 | 否：存于应用私有目录 |

**关键事实：通知使用权在系统层面是全局的。** 代码里只处理 `com.tencent.mobileqq` /
`com.tencent.qqlite` / `com.tencent.tim`，但权限本身允许读取设备上任何应用的通知。
用户应当知晓并同意这一点，而不是被“我们只读 QQ”这句话安抚过去。

## 2. 通知数据的处理规则

- 只处理 QQ 家族包名，其余通知在 `onNotificationPosted` 第一行就被丢弃；
- 最近 80 条保存在**内存**里（`NotificationBus`），进程结束即消失，不落盘；
- 进入 LLM prompt 时最多取最近 6 条，并截断到 900 字符；
- 只有“有任务在跑”或“自动回复触发”时才会读取这批内存数据；
- 自己刚发出的消息会通过 `ReplyLedger` 在 20 秒内抑制，避免自我循环。

## 3. 发送给 LLM 的内容

默认（未开启视觉）每一轮发送：

1. 系统提示（人格 + 动作规范，固定文本）；
2. 用户目标；
3. 当前前台应用包名、屏幕分辨率；
4. **裁剪后的界面描述**：节点编号、控件类型、可见文字、contentDescription、hint、
   是否可点击/可编辑/可滚动、bounds 坐标；
5. 最近 8 步动作与结果；
6. 最近 6 条通知摘要（仅当存在时）；
7. 压缩后的长期记忆（最多 900 字符）。

**不会发送**：密码框的输入内容、剪贴板内容、通讯录、相册、文件、其他应用的通知原文
（除非它恰好是 QQ 且进入了最近 6 条）。

## 4. 密码与验证码

- `AccessibilityNodeInfo.isPassword == true` 的节点，在快照里只保留 `PASSWORD` 标记，不取明文；
- `SafetyPolicy` 对任何指向密码/验证码输入框的 `input` 动作直接判定 `FORBIDDEN`；
- `WhaleAccessibilityService.setText()` 在服务层再拒绝一次；
- 系统权限弹窗、系统设置页面**禁止代点**。

## 5. 本地存储与清除

| 文件 | 内容 | 清除方式 |
|---|---|---|
| `SharedPreferences(whale_settings)` | 设置项 + 加密后的 API Key | 设置页清空 Key / 清除应用数据 |
| `Android Keystore` 别名 `whale_chan_llm_api_key_v1` | AES-256-GCM 密钥（不可导出） | `KeystoreHelper.resetKey()` / 清除应用数据 |
| `files/whale_memory.json` | 事实、任务摘要、最近聊天 | `MemoryStore.clear()` / 清除应用数据 |

卸载应用会同时删除以上全部内容。

## 6. 用户配置的 LLM 端点

- 端点由用户自己填写，通常是 OpenAI、DeepSeek、OpenRouter、自建 vLLM/Ollama；
- 这些第三方会收到 §3 列出的内容，其日志与留存策略由该服务商决定，本应用无法控制；
- 使用 `http://` 局域网端点时，API Key 与内容在局域网内**明文传输**，设置页会显示警告；
- 建议：使用专用 Key、设置额度上限、不要用主账号 Key。

## 7. 权限撤回

- 无障碍：设置 → 无障碍 → 关闭鲸鱼娘；
- 通知使用权：设置 → 通知使用权 → 取消勾选；
- 电池优化：设置 → 电池 → 电池优化 → 鲸鱼娘 → 允许优化；
- 悬浮窗：设置 → 应用 → 显示在其他应用上层 → 关闭。

任一权限撤回后，对应功能立即失效，应用不会尝试绕过。

## 8. 合规提醒

- 自动化操作可能违反 QQ、抖音等平台的用户协议，账号存在被限制/封禁的风险；
- 本应用仅面向**个人设备、个人账号、个人使用**；
- 不得用于批量养号、刷量、骚扰他人、绕过平台风控；
- Google Play 对无障碍 API 的用途审核极严，此类应用通常只能侧载或企业内部分发，
  上架前必须重新评估政策合规性。
