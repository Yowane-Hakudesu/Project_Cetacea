>“哼，本鲸鱼才不是大肥鱼！Master，今天要让我帮你干点啥？”

**WhaleChan** 是一个运行在 Android 端的本地自动化 AI Agent。她常驻在你的手机后台，通过你配置的 LLM（大语言模型）进行思考，并利用 Android 无障碍服务（Accessibility Service）代替你操作手机（如打开 QQ、发消息、刷视频等）。

当前版本：**v0.2.0**

---

## ⚠️ 重要声明（新手必读）

> **本项目处于早期测试阶段，请谨慎使用！**
> 1. 本项目需要极高的系统权限（无障碍、通知监听），**请务必在备用机或清楚风险的情况下测试**。
> 2. Agent 由 LLM 驱动，可能会产生不可预知的误触（如误点广告、误发消息）。
> 3. Android 系统限制极多，遇到卡死、被杀后台属于正常现象。
> 4. **完全信任模式（FULL_TRUST）** 会关闭全部操作前确认，误操作不可撤销，只留事后日志。

## ✨ v0.2.0 核心功能

- [x] **拟人化人格**：内置 `[PERSONA_LOAD]` 系统提示词，傲娇、甜、爱吃米饭的“鲸鱼娘”人格；卡住时会说“……哼，卡住了啦”。
- [x] **LLM 自由配置**：支持任意 OpenAI 兼容 API（Base URL、API Key、Model ID），API Key 本地加密存储。
- [x] **视觉感知与操作**：读取无障碍节点树 → LLM 规划动作 → 执行点击 / 滑动 / 输入。
- [x] **三档步数策略**：有限步数（到上限弹窗问「继续 / 放弃」）、时间窗口、无限模式。
- [x] **防卡死保护**：连续多步界面不变自动判定卡住，并说明卡在哪里。
- [x] **结构化执行日志**：每一步记录动作、执行前后的界面指纹、LLM 原始响应，自动清理（最多 5000 条 / 7 天）。
- [x] **熄屏长时响应**：前台服务 + WakeLock + 网络心跳，另附「熄屏诊断」页面。
- [x] **完全信任模式 FULL_TRUST**：可关闭所有操作前确认；代填密码是**另一道独立开关**，默认关闭。
- [x] **SMART_LAZY 动作缓存**：遇到同样界面时优先回放上次成功的动作序列。
- [x] **通知监听联动**：监听 QQ 等应用通知，交由 Agent 决策是否回复。
- [x] **远程伴侣（局域网）**：手机端开 WebSocket 服务端，另一台设备连上来聊天 / 下任务 / 远程确认 / 叫停。

## 🛠️ 必读：系统权限清单

没有这些权限，WhaleChan 将无法行动。请在手机设置中手动授予：

| 权限名称 | 用途 | 缺失后果 |
| :--- | :--- | :--- |
| **无障碍服务 (Accessibility)** | 核心。用于读取屏幕、模拟点击、滑动和打字 | 完全无法执行任何操作，变成纯聊天框 |
| **通知使用权 (Notification Listener)** | 读取 QQ 等应用的通知 | 无法主动获知谁发了消息，无法触发回复任务 |
| **电池优化白名单** | 防止系统在息屏后杀掉后台进程 | 息屏几分钟后彻底失联，任务执行到一半卡住 |
| **悬浮窗（可选）** | Android 10+ 后台拉起 QQ 等应用 | `open_app` 会退化成“发一条通知请你点一下” |
| **通知权限 (API 33+)** | 常驻通知、步数上限询问、确认请求 | 无法弹「继续 / 放弃」，到上限会按放弃处理 |
| **网络权限** | 调用 LLM 接口、局域网伴侣通道 | 无法思考，伴侣模式连不上 |

## 🚀 快速开始 (新手教程)

### 1. 安装 App
下载 `app-debug.apk` 装到手机（从 Releases 或构建产物）。

### 2. 配置 LLM 大脑
1. 打开 WhaleChan App → **设置**页面。
2. 填入你的 LLM 信息（推荐支持 JSON 输出的模型，如 GPT-4o、Claude 3.5、DeepSeek 等）。
   - **Base URL**: 例如 `https://api.openai.com/v1`
   - **API Key**: `sk-xxxxxx`
   - **Model ID**: 例如 `deepseek-chat`
3. 点击“测试连接”确保成功。

### 3. 授予权限并启动
1. 首页点“去开启无障碍”，跳转系统设置勾选 WhaleChan（侧载应用需先「允许受限设置」）。
2. 点“去开启通知使用权”，勾选 WhaleChan。
3. 点“去关闭电池优化”，加入白名单。
4. （建议）允许悬浮窗，让后台也能打开其他应用。
5. 回到首页点“启动常驻服务”，通知栏出现常驻通知。

### 4. 选择步数策略（设置页 ⑤）
- **A 有限步数**：默认 50 步，到上限会发通知问「继续 / 放弃」；
- **B 时间窗口**：只看时间，默认 30 分钟，0 表示不限时；
- **C 无限模式**：必须勾选「我理解可能耗电与发热」，只有完成、卡死或你手动停止才结束。

### 5. 下达任务
在聊天框输入，例如：`打开QQ，给置顶好友发一句晚安`，观察她的执行。

## 📡 远程伴侣（局域网）

> v0.2.0 的伴侣功能是**手机端 App 内置的一个页面**（不叫独立 App），
> 想用另一台设备遥控时，在那台设备上也装同一个 APK，打开「伴侣模式」。

### 在手机端（被操控端）开启
1. 设置页 ⑥ → 打开「开启 WebSocket 服务端」，端口默认 `8787`；
2. 记下显示的**地址**和**配对码**；
3. 手机端会通过 mDNS 广播，同网段设备可以自动发现。

### 在另一台设备上连接
1. 打开同一个 App → 进入**伴侣模式**；
2. 填手机端的 `IP:8787` 与配对码（或点搜索自动发现）；
3. 连上后有三种用法：
   - **聊天模式**：只聊天，不下发任务；
   - **任务模式**：发一句话就是一条任务指令；
   - **远程确认**：手机端需要确认时，伴侣端会弹窗，可以点「确认 / 拒绝」；
   - 随时可以按「停止」叫停当前任务。

### 连不上怎么办
- 两台设备必须**连同一个 Wi-Fi**；
- 只在手机设置页显示的 `192.168.x.x` 地址可用，蜂窝网的 `10.x` 地址从外部连不上；
- 校园网、访客网络常开客户端隔离，会连不上——这种情况用手机开热点，填热点网关地址（通常是 `192.168.43.1:8787`）；
- 断线后伴侣端会重连，心跳间隔 30 秒。

## 🧠 技术架构简图

```text
[用户指令 / QQ 通知 / 伴侣端消息]
      ↓
[LLM 规划器] (解析意图，生成动作 JSON)
      ↓
[Agent 循环] (三档步数策略 / 防卡死 / 每步落库)
      ↓
[无障碍服务] (抓取 UI 树 -> 注入点击/滑动事件)
      ↓
[手机屏幕] (执行结果 -> 下一轮观察)
```

远程伴侣是独立的一条通道：

```text
[伴侣端] ──ws://ip:8787 (hello + 配对码, 30s 心跳)──> [手机端 WebSocket 服务端]
                                                        ↓ 指令：chat / stop / confirm_result
                                                    [Agent 引擎]
                                                        ↑ 广播：状态 / 每步日志 / 确认请求 / 任务结束
```

## 📋 执行日志与排错

设置页里能查最近的执行记录，每条包含：

| 字段 | 含义 |
| :--- | :--- |
| 步骤序号 | 第几步 |
| 动作 | 点击 / 滑动 / 输入 / 打开应用…… |
| 执行前 / 后界面指纹 | 用来判断这一步到底有没有生效 |
| LLM 原始响应 | 模型当时输出的 JSON |
| 错误分类 | 找不到节点 / 手势超时 / 权限丢失 / 卡死…… |

常见错误分类：`NODE_NOT_FOUND`（按钮不见了）、`GESTURE_TIMEOUT`（系统不让我点）、
`PERMISSION_LOST`（无障碍掉线）、`STUCK`（连续多步界面不变）、`LLM_INVALID_ACTION`（模型输出不合法）。

## 🐛 常见问题

- **她说“卡住了啦”**：界面连续多步没变化，看日志里是哪一步没生效。
- **打不开别的 App**：Android 10+ 限制后台启动，允许悬浮窗或手动点一下通知。
- **息屏后失联**：检查电池优化白名单，部分厂商还要单独开「后台自启 / 锁屏运行」。
- **伴侣端连不上**：见上面「连不上怎么办」。
- **想让她别乱点**：别开 FULL_TRUST；付款、系统设置、删除类动作永远需要确认。
