>“哼，本鲸鱼才不是大肥鱼！Master，今天要让我帮你干点啥？”

**WhaleChan** 是一个运行在 Android 端的本地自动化 AI Agent。她常驻在你的手机后台，通过你配置的 LLM（大语言模型）进行思考，并利用 Android 无障碍服务（Accessibility Service）代替你操作手机（如打开 QQ、发消息、刷视频等）。

从 v0.3.0 起，她有了一个**独立的伴侣端 App**：用另一台手机或平板跟她聊天、发图片和文件、随时叫停。v0.3.1 主要修掉了“无限模式下干两下就自己停下”的问题。

当前版本：**v0.3.1**

## ⚠️ 重要声明（新手必读）

> **本项目仍处测试阶段，请谨慎使用！**
> 1. 本项目需要极高的系统权限（无障碍、通知监听），**请务必在备用机或清楚风险的情况下测试**。
> 2. Agent 由 LLM 驱动，可能会产生不可预知的误触（如误点广告、误发消息）。
> 3. Android 系统限制极多，遇到卡死、被杀后台属于正常现象。
> 4. **完全信任模式（FULL_TRUST）** 会关闭全部操作前确认，误操作不可撤销，只留事后日志。
> 5. 自动化操作可能违反 QQ、抖音等平台的用户协议，账号风险自负。

## ✨ v0.3.1 核心功能

- [x] **拟人化人格**：内置 `[PERSONA_LOAD]` 系统提示词，傲娇、甜、爱吃米饭的“鲸鱼娘”人格；卡住时会说“……哼，卡住了啦”，并附上真实原因。
- [x] **LLM 自由配置**：支持任意 OpenAI 兼容 API（Base URL、API Key、Model ID），API Key 本地加密存储。
- [x] **视觉感知与操作**：读取无障碍节点树 → LLM 规划动作 → 执行点击 / 滑动 / 输入。
- [x] **三档步数策略**：有限步数（到上限弹窗问「继续 / 放弃」）、时间窗口、无限模式。
- [x] **无限模式跑得住了**：打开别的 App 会等它真正进入前台，失败会自己换策略重试，不会再第 2 步就停下。
- [x] **开放式任务自动驾驶**：说“随便玩”“干你想干的”，她会自己找事做，不会草草收场。
- [x] **结构化执行日志**：每一步记录动作、前后界面指纹、LLM 原始响应，自动清理（最多 5000 条 / 7 天）。
- [x] **熄屏长时响应**：前台服务 + WakeLock + 心跳，另附「熄屏诊断」页面。
- [x] **完全信任模式 FULL_TRUST**：可关闭所有操作前确认；代填密码是**另一道独立开关**，默认关闭。
- [x] **通知监听联动**：监听 QQ 等应用通知，交由 Agent 决策是否回复。
- [x] **独立伴侣端 App**：聊天式界面、可换聊天背景、可以给她发图片和文件、远程叫停与确认。

  当然，她能做的事情远不止这些......

## 🆕 v0.3.1 修了什么

如果你遇到过“开了无限模式，她才打开 QQ 就弹出『没做成，已停下』”，这一版就是为你修的：

| 问题 | 原因 | 现在 |
| :--- | :--- | :--- |
| 第 2 步就停下 | 打开 QQ 时后台服务被系统回收，顺手把任务取消了 | 服务被回收不再打断任务 |
| 抓到白屏就规划 | 应用还没渲染完就开始截图式观察 | 等目标应用真正进入前台，再等 1 秒开屏广告 |
| 说她卡住了 | 视频在动但文字没变，也被算成“界面变化” | 只看界面上的文字有没有变 |
| 一直卡也不停 | 步数与时间都只看一个 | 连续 15 步或连续 30 秒没变化才判定卡住 |
| 一次点不中就放弃 | 交互失败直接结束任务 | 失败原因喂回模型，让她换个走法重试 |

## 🛠️ 必读：系统权限清单

没有这些权限，WhaleChan 将无法行动。请在手机设置中手动授予：

| 权限名称 | 用途 | 缺失后果 |
| :--- | :--- | :--- |
| **无障碍服务 (Accessibility)** | 核心。用于读取屏幕、模拟点击、滑动和打字 | 完全无法执行任何操作，变成纯聊天框 |
| **通知使用权 (Notification Listener)** | 读取 QQ 等应用的通知 | 无法主动获知谁发了消息，无法触发回复任务 |
| **电池优化白名单** | 防止系统在息屏后杀掉后台进程 | 息屏几分钟后彻底失联，任务执行到一半卡住 |
| **悬浮窗（可选）** | Android 10+ 后台拉起 QQ 等应用 | `open_app` 会退化成“发一条通知请你点一下” |
| **通知权限 (API 33+)** | 常驻通知、步数上限询问、确认请求 | 无法弹「继续 / 放弃」，到上限会按放弃处理 |
| **网络权限** | 调用 LLM 接口、局域网伴侣通道 | 无法思考，伴侣端连不上 |

## 🚀 快速开始 (新手教程)

### 1. 安装 App
- **手机端** `app-debug.apk`：装到要被她操作的手机；
- **伴侣端** `companion-debug.apk`：可选，装到另一台设备。

### 2. 配置 LLM 大脑
1. 打开 WhaleChan App → **设置**页面。
2. 填入你的 LLM 信息（推荐支持 JSON 输出的模型，如 GPT-4o、Claude 3.5、DeepSeek 等）。
   - **Base URL**: 例如 `https://api.openai.com/v1`
   - **API Key**: `sk-xxxxxx`
   - **Model ID**: 例如 `deepseek-chat`
3. 点击“测试连接”确保成功。

### 3. 授予权限并启动
1. 首页点“去开启无障碍”，跳转系统设置勾选 WhaleChan（侧载应用需先「允许受限设置」）。
2. 点“去开启通知使用权”，勾选 WhaleChan。
3. 点“去关闭电池优化”，加入白名单。
4. （建议）允许悬浮窗，让后台也能打开其他应用。
5. 回到首页点“启动常驻服务”，通知栏出现常驻通知。

### 4. 选择步数策略（设置页 ⑤）
- **A 有限步数**：默认 50 步，到上限会发通知问「继续 / 放弃」；
- **B 时间窗口**：只看时间，默认 30 分钟，0 表示不限时；
- **C 无限模式**：必须勾选「我理解可能耗电与发热」，只有完成、卡死或你手动停止才结束。

> 想在应用之间自己逛，选 C。现在即使目标应用冷启动慢，她也会等你。

### 5. 下达任务
在聊天框输入，例如：`打开QQ，给置顶好友发一句晚安`，观察她的执行。

> 「允许我动手」现在**默认开启**：发出去的话会被当作任务执行；关掉它就只是聊天。

## 📡 远程伴侣（独立 App）

### 手机端（被操控端）开启
1. 设置页 ⑥ → 打开「开启 WebSocket 服务端」，端口默认 `8787`；
2. 记下显示的**地址**（形如 `192.168.1.23:8787`）与**配对码**；
3. 手机端会通过 mDNS 广播，同网段可以自动发现。

### 伴侣端连接
1. 安装 `companion-debug.apk` 到另一台设备，打开后点顶部「未连接 · 点这里设置」；
2. 点「查找局域网设备」自动搜索，或手动填 `IP:8787` + 配对码；
3. 连上后：
   - 输入框右侧切「聊天 / 任务」，任务模式下发的话就是指令；
   - 回形针可发**图片**或**文件**（均 ≤ 4MB，图片自动压缩）；
   - 她需要确认时会弹窗，可以点「确认执行 / 不要」；
   - 随时可以叫停当前任务；
   - 右上角菜单可更换聊天背景。

### 连不上怎么办
- 两台设备必须**连同一个 Wi-Fi**；
- 只填手机端显示的 `192.168.x.x`，蜂窝网的 `10.x` 地址从外部连不上；
- 校园网、访客网络常开客户端隔离，会连不上——用手机开热点，填热点网关（通常 `192.168.43.1:8787`）；
- 心跳间隔 30 秒，断线会自动重连。

## 🧠 技术架构简图

```text
[用户指令 / QQ 通知 / 伴侣端消息]
      ↓
[LLM 规划器] (解析意图，生成动作 JSON)
      ↓
[Agent 循环] (三档步数策略 / 冷启动等待 / 失败重试 / 每步落库)
      ↓
[无障碍服务] (抓取 UI 树 -> 注入点击/滑动事件)
      ↓
[手机屏幕] (执行结果 -> 下一轮观察)
```

远程伴侣是另一条通道：

```text
[伴侣端] ──ws://主机IP:8787 (hello + 配对码, 30 秒心跳)──> [手机端 WebSocket 服务端]
                                                          ↓ 指令：chat / stop / confirm / attachment
                                                      [Agent 引擎]
                                                          ↑ 广播：状态 / 每步动作 / 确认请求 / 任务结束
```

## 📋 执行日志与排错

设置页里能查最近的执行记录，每条包含：步骤序号、动作、执行前后界面指纹、LLM 原始响应、错误分类。

| 错误分类 | 含义 |
| :--- | :--- |
| `NODE_NOT_FOUND` | 按钮不见了，界面可能改版或被弹窗挡住 |
| `GESTURE_TIMEOUT` | 系统拒绝注入点击，检查无障碍是否存活 |
| `APP_LAUNCH_TIMEOUT` | 目标应用 5 秒内没进入前台（冷启动慢、停在开屏广告） |
| `PERMISSION_LOST` | 无障碍或通知权限掉了 |
| `SCREEN_STATE_DRIFT` | 执行完界面被切走，可能弹了新窗口或锁屏 |
| `STUCK` | 连续多步界面没有有效变化 |
| `LLM_INVALID_ACTION` | 模型输出的动作不合法 |
| `AUTONOMOUS_FALLBACK` | 模型没给出可用动作，她自己滑了一下继续（不是故障） |

## 📦 两个 APK 的区别

| | 手机端 `app-debug.apk` | 伴侣端 `companion-debug.apk` |
| :--- | :--- | :--- |
| 包名 | `com.whalechan.agent` | `com.whalechan.companion` |
| 作用 | 真正执行任务的被操控端 | 聊天 / 派活 / 发图片文件的遥控端 |
| 需要的权限 | 无障碍、通知监听、电池白名单 | 仅网络 |

## 🐛 常见问题

- **她说“被系统中断”**：不是她判断错了，是后台被厂商杀了；检查电池优化白名单与后台自启。
- **打不开某个 App**：看日志里的 `APP_LAUNCH_TIMEOUT`，通常停在开屏广告或登录页，再试一次或手动点一下。
- **她说“卡住了啦”**：界面连续 15 步或 30 秒没有文字变化，看日志里是哪一步没生效。
- **她自己乱动**：那是开放式任务的自动驾驶；想让她只做指定的事，就别说“随便玩”。
- **她乱点 / 停不下来**：按聊天页右下角的「停」，或伴侣端的停止按钮。
- **伴侣端连不上**：见上面「连不上怎么办」。
