>“Master 在外面也要管着我吗？……哼，好吧，那我听你的。”

**鲸鱼娘·遥控**是 [Project_Cetacea](https://github.com/Yowane-Hakudesu) 的**独立伴侣端 App**。
它不干活，只负责遥控：用另一台手机或平板，跟住在主手机里的鲸鱼娘聊天、派任务、发图片和文件、随时叫停。

包名：`com.whalechan.companion`｜版本：**v0.3.0**

> **配套版本**：伴侣端 v0.3.0 需要主机端 **app v0.3.0 及以上**。
> v0.2.0 的手机端没有独立的伴侣 App，用的是 App 内置的「伴侣模式」页面，不兼容本程序。

---

## ✨ 她能替你做什么

- [x] **聊天式界面**：消息气泡、头像、时间分隔、已发送标记，和主流聊天软件一致。
- [x] **聊天即指令**：底部开关切「聊天 / 任务」，任务模式下你发的话会变成她的待办。
- [x] **发图片**：从相册选图，自动压缩后发送，她能看到图。
- [x] **发文件**：分享任意文件给她，落盘保存并作为任务上下文。
- [x] **远程确认**：主机端需要确认操作时，这里会弹窗，点「确认执行 / 不要」。
- [x] **随时叫停**：一键停止正在执行的任务。
- [x] **自定义聊天背景**：换成你自己的图，随时恢复默认。
- [x] **自动发现设备**：同一 Wi-Fi 下可搜索主机，不用手抄 IP。
- [x] **记住上次连接**：打开 App 自动重连。

## 🛠️ 权限说明

伴侣端**只需要网络相关权限**，不需要无障碍、不需要通知监听，比主机端安全得多：

| 权限 | 用途 | 缺失后果 |
| :--- | :--- | :--- |
| INTERNET / ACCESS_NETWORK_STATE | 连接主机端 WebSocket | 完全无法使用 |
| CHANGE_WIFI_MULTICAST_STATE | mDNS 搜索局域网内的主机 | 只能手动输入 IP |

> 选择相册图片/文件用的是系统选择器，**不会申请存储权限**。

## 🚀 快速开始

### 1. 先在主机端准备
1. 主机手机装好 `app-debug.apk`，授予无障碍 / 通知 / 电池白名单；
2. 设置页「⑥ 远程伴侣」→ 打开 **「开启 WebSocket 服务端」**（端口默认 8787）；
3. 记下页面上显示的 **地址**（形如 `192.168.1.23:8787`）和 **配对码**（12 位字母数字）。

### 2. 在伴侣端连接
1. 安装 `companion-debug.apk` 到另一台设备；
2. 点顶部状态栏「未连接 · 点这里设置」；
3. 两种连法：
   - **自动搜索**：点「查找局域网设备（直连时可选）」，选中鲸鱼娘所在的设备；
   - **手动填写**：直接输入 `192.168.1.23:8787` 和配对码；
4. 点「连接」，顶部显示「已连接 · …」就成功了。

### 3. 开始使用
- 输入框打字 → 点纸飞机发送；
- 输入框右侧的「聊天 / 任务」开关决定这条消息是闲聊天还是派活；
- 左下角回形针 → 「发送图片」或「发送文件」；
- 右上角菜单 → 更换聊天背景 / 恢复默认背景 / 连接手机 / 断开连接。

## 📮 发送图片与文件

| 类型 | 上限 | 说明 |
| :--- | :--- | :--- |
| 图片 | 压缩后 ≤ 4MB | 自动缩放到长边 1600px 内，再按质量逐级压缩 |
| 文件 | ≤ 4MB | 超过会直接提示，不会悄悄截断 |

- 图片可以直接被她的视觉模型看到（如果主机端开启了视觉）；
- 文件会保存在主机端的私有目录，她能在任务里读到路径和文件名；
- 发送成功后，主机端会回一条「已收到图片 / 文件」的提示。

## 🔌 连接原理

```text
[伴侣端 App] ──ws://主机IP:8787 (hello + 配对码, 30 秒心跳)──> [主机端 WebSocket 服务端]
                                                              ↓ 指令：聊天 / 任务 / 停止 / 确认结果
                                                          [Agent 引擎]
                                                              ↑ 广播：状态 · 每步动作 · 确认请求 · 任务结束
```

- 只走局域网，**不经过任何服务器**，聊天内容不会上传；
- 没有 TLS，配对码泄露等于控制权泄露，**不要在公共 Wi-Fi 上开启**；
- 断线后会自动重连，重连时沿用上次的地址与配对码。

## ❓ 连不上怎么办

| 现象 | 原因与处理 |
| :--- | :--- |
| `Host unreachable` | 两台设备不在同一网络，或填了运营商地址 `10.x`。只填主机端显示的 `192.168.x.x` |
| 一直「连接中…」 | 主机端服务端没开、端口填错，或被路由器 AP 隔离挡住 |
| `BAD_TOKEN` / 立刻断开 | 配对码不对，去主机端重新抄一遍 |
| 校园网连不上 | 校园网通常做客户端隔离。让主机开热点，伴侣端连热点，填热点网关（一般 `192.168.43.1:8787`） |
| 连上又断 | 主机被系统杀了后台，去检查电池优化白名单 |

## 📱 与主机端的关系

| | 主机端 `app-debug.apk` | 伴侣端 `companion-debug.apk` |
| :--- | :--- | :--- |
| 包名 | `com.whalechan.agent` | `com.whalechan.companion` |
| 作用 | 真正执行任务的被操控端 | 聊天 / 派活 / 发图片文件的遥控端 |
| 权限 | 无障碍、通知监听、电池白名单 | 仅网络 |
| 是否必需 | 必需 | 可选 |

两个 App 可以装在同一台手机上，也可以分装两台。**不要装混**：伴侣端本身不会操作屏幕。
