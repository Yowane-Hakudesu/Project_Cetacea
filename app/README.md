> “哼，本鲸鱼才不是大肥鱼！Master，今天要让我帮你干点啥？”

**鲸鱼娘** 是运行在你 Android 手机上的端侧自动化 Agent：她常驻后台，用你配置的 LLM 思考，
通过无障碍服务替你点屏幕、发消息、刷视频；通过通知监听知道谁找了你。

这是**手机端（被操控端）**的说明。遥控端是另一个独立 App：**鲸鱼娘·遥控**，
见 [companion/README.md](../companion/README.md)。

当前版本：**v0.4.0**（versionCode 5，协议 v2）

## ⚠️ 重要声明（新手必读）

> **本项目仍处测试阶段，请谨慎使用！**
> 1. 需要极高的系统权限（无障碍、通知监听），请优先在备用机上测试。
> 2. Agent 由 LLM 驱动，可能误触广告、误发消息，**完全信任模式下不可撤销**。
> 3. 节流与复读熔断只能降低“刷屏”概率，不能保证 100% 不重复。
> 4. 自动化操作可能违反 QQ、抖音等平台的用户协议，账号风险自负。
> 5. 中继服务器如果裸露在公网且不设令牌，等于把手机控制权交给任何人。

## ✨ v0.4.0 核心功能

- [x] **拟人化人格**：`[PERSONA_LOAD]` 系统提示词，傲娇、甜、爱吃米饭的鲸鱼娘；卡住时说“……哼，卡住了啦”，并附真实原因。
- [x] **LLM 自由配置**：任意 OpenAI 兼容 API（Base URL / API Key / Model ID），Key 用 Android Keystore 加密。
- [x] **视觉 + 无障碍操作**：读节点树 → LLM 规划 → 点击 / 滑动 / 输入 / 打开应用。
- [x] **三档步数策略**：有限步数（到上限询问）、时间窗口、无限模式（需勾选风险确认）。
- [x] **社交行为节流**：同一好友 30 秒 1 条、全局 1 分钟 3 条；说说 24 小时 2 条；同一条动态评论 1 次；转发 30 分钟 10 次。
- [x] **实体记忆**：聊天页提取好友名注入 `[CurrentEntity]`；最近 30 分钟社交动作注入 `[RecentActivity]`，防止重复评论/连发。
- [x] **分段发送**：回复按句拆成 ≤15 字短消息，间隔 1.5~3 秒逐条发，模拟真人节奏。
- [x] **复读熔断**：与最近 3 条已发文本相似度 ≥80% 直接拦截。
- [x] **通知冷却信箱**：刷视频/看内容时不被打断，QQ 消息先排队，任务结束再处理。
- [x] **公网中继**：校园网 AP 隔离也能用；手机主动连 `wss://` 中继，按配对码跨网通信。
- [x] **结构化日志**：每步记录动作、前后指纹、LLM 原始响应、错误分类；最多 5000 条 / 7 天。
- [x] **完全信任 FULL_TRUST**：关闭操作前确认；代填密码是另一道独立开关，默认关闭。
- [x] **任务结束离场**：结束或失败后若还停在 QQ/TIM，主动回桌面。

## 🆕 v0.4.0 改了什么

| 你遇到的问题 | v0.4.0 的处理 |
| :--- | :--- |
| 无限模式下在 QQ 疯狂切窗口、连发 7 条说说 | `ActionRateLimiter` 前置拦截，返回 `ActionRejected: Cooldown`，模型必须换目标 |
| 同一条动态被评论好几次 | 屏幕文本指纹当 Post ID，生命周期内只允许 1 次；30 分钟内的动作写进 `[RecentActivity]` |
| 认不清在跟谁聊天 | 聊天页标题栏提取 `[CurrentEntity]`，每轮注入“当前正在与「夏」对话” |
| 一条回复拆成七八段、像复读机 | `SOCIAL_STYLE` 强制 ≤15 字一句；`TextSegmenter` 分条 + 随机延迟 |
| 刷视频时被 QQ 消息打断 | `PendingInbox` 暂存消息，当前任务结束后再取一条处理 |
| 校园网/蜂窝网连不上伴侣端 | 新增公网中继（`relay/server.js`），不再依赖同一 Wi-Fi |
| 任务结束还赖在聊天窗口 | 主动 `performHome()` 回桌面 |
| 模型反复说同一句话 | 相似度熔断；连续 3 次才判定卡死，而不是一次就结束 |

## 🛠️ 必读：系统权限清单

| 权限 | 用途 | 缺失后果 |
| :--- | :--- | :--- |
| **无障碍服务** | 读屏、点击、滑动、输入 | 完全无法操作，只剩聊天 |
| **通知使用权** | 读取 QQ 等通知，触发回复 | 不知道谁发了消息，自动回复失效 |
| **电池优化白名单** | 防止息屏/切后台被杀 | 任务跑到一半失联 |
| **悬浮窗（可选）** | Android 10+ 后台拉起其他 App | `open_app` 退化为“发通知请你点一下” |
| **通知权限（API 33+）** | 常驻通知、步数上限询问、确认请求 | 到上限直接按放弃处理 |
| **网络权限** | LLM 请求、中继/局域网通道 | 无法思考，遥控端连不上 |

## 🚀 快速开始

### 1. 安装
- 手机端：`app-debug.apk`（本模块产物）；
- 遥控端（可选）：`companion-debug.apk`，装到另一台手机/平板。

### 2. 配置 LLM
设置页填入：
- **Base URL**：`https://api.openai.com/v1`、`https://api.deepseek.com/v1` 等；
- **API Key**：加密保存在本机；
- **Model ID**：如 `deepseek-chat`、`gpt-4o-mini`；
- 点「测试连接」。

### 3. 授权并启动
1. 无障碍 → 鲸鱼娘（侧载需先「允许受限设置」）；
2. 通知使用权 → 鲸鱼娘；
3. 电池优化 → 不限制；
4. （建议）悬浮窗；
5. 回首页「启动常驻服务」。

### 4. 选步数策略（设置页 ⑤）
- **A 有限步数**：默认 50，到上限弹「继续 / 放弃」；
- **B 时间窗口**：默认 30 分钟，0 = 不限时；
- **C 无限模式**：勾选风险确认；只有完成、真卡死或你按停才结束。

### 5. 下达任务
聊天框输入：`打开QQ，给置顶好友发一句晚安`。

> 「允许我动手」**默认开启**并记住你的选择：发出去的话会当任务执行；关掉就只是聊天。

## 📡 遥控端连接（两种方式）

### 方式 A：公网中继（推荐，校园网可用）

1. 部署 `relay/server.js`（见 [relay/README.md](../relay/README.md)），拿到 `wss://你的域名/ws` 和 `RELAY_TOKEN`；
2. 手机端设置页 ⑥：
   - 打开「公网中继」；
   - 填中继地址与令牌；
   - 记下 **6 位中继配对码**（可重新生成）；
3. 遥控端填同一个地址、令牌、配对码即可。

手机端会主动连出，断线 5 秒自动重连；不需要公网 IP、不需要同一 Wi-Fi。

### 方式 B：局域网直连（同一 Wi-Fi）

1. 设置页 ⑥ 打开「WebSocket 服务端」，端口默认 `8787`；
2. 遥控端填 `192.168.x.x:8787` + 手机端「配对码」，**中继配对码留空**。

> 校园网有 AP 隔离时直连必失败（`Host unreachable`），请用方式 A 或手机热点。

### 遥控端能做什么
- 发文字：聊天模式只聊天；任务模式发送 `COMMAND`，手机端直接 `startTask()`；
- 发图片/文件（≤4 MB，图片自动压缩）；
- 实时看到 `THINKING / EXECUTING_ACTION / WAITING / IDLE` 与每步 `errorDetail`；
- 远程叫停、确认危险动作、换聊天背景。

## 🧠 技术架构

```text
[用户指令 / QQ 通知 / 遥控端 COMMAND]
        ↓
[AgentEngine 主循环]
  ├─ 提取 [CurrentEntity] + [RecentActivity]
  ├─ 社交节流 ActionRateLimiter（FULL_TRUST 也拦）
  ├─ 复读熔断 TextSimilarity
  ├─ LLM 规划（JSON 动作）
  ├─ ActionExecutor（无障碍点击/滑动/输入/打开应用）
  └─ 每步落库 StepLog（Room）
        ↓
[手机屏幕]
```

遥控通道：

```text
[鲸鱼娘·遥控] ──wss──> [relay/server.js] <──wss── [鲸鱼娘]
        └────────── 同一 pairCode ──────────┘
```

中继只转发，不解析、不落盘；状态与错误通过 `state` / `step` 消息实时回传。

## 📋 日志与错误分类

设置页可查最近执行记录：步骤、动作、前后指纹、LLM 原始响应、错误分类。

| 分类 / 标记 | 含义 |
| :--- | :--- |
| `NODE_NOT_FOUND` | 按钮不见了，界面改版或被弹窗遮挡 |
| `GESTURE_TIMEOUT` | 系统拒绝注入手势，检查无障碍 |
| `APP_LAUNCH_TIMEOUT` | 目标应用 5 秒内没进前台（开屏广告/登录页） |
| `PERMISSION_LOST` | 无障碍/通知权限掉了 |
| `SCREEN_STATE_DRIFT` | 执行后界面被切走 |
| `STUCK` | 连续 15 步或 30 秒没有有效变化 |
| `LLM_INVALID_ACTION` | 模型输出不是合法动作 |
| `AUTONOMOUS_FALLBACK` | 模型没给可用动作，她自行滑一下继续（不是故障） |
| `RATE_LIMITED` | 触发社交冷却，动作未执行 |
| `DUPLICATE_TEXT` | 与最近 3 条过于相似，被复读熔断 |
| `DUPLICATE_ACTION` | 10 分钟内相同动作已成功过 |

## 🐛 常见问题

- **她说“被系统中断”**：后台被厂商杀了，检查电池白名单/自启；v0.4 起服务销毁不会再取消任务。
- **一直弹「ActionRejected: Cooldown」**：这是节流，不是故障；等冷却或换目标。
- **她说“这句话刚说过”**：复读熔断；让她换话题，或直接结束任务。
- **刷视频时消息没回**：在 `PendingInbox` 里排队，当前任务结束会自动处理。
- **遥控端连不上**：校园网优先用中继；直连要同一 Wi-Fi，且填 `192.168.x.x`，不要填 `10.x`。
- **中继能连但没反应**：检查两端 `RELAY_TOKEN` 与配对码是否完全一致；手机端看「中继：ONLINE」。
- **她乱点/停不下来**：聊天页「停」；遥控端也有停止按钮。

## 🔐 安全与限制

- 节流依赖 Room 账本，进程重启后仍然有效；但评论的 Post 指纹来自屏幕文本，动态标题变化会生成新 key。
- `CurrentEntity` 是布局启发式，不同 QQ 版本可能识别失败（会退回“未知”，不会编造好友名）。
- 分段发送可能因为输入框/发送按钮改版而中断，已发部分会如实报告。
- 中继是明文 WebSocket 终点，生产必须用 Nginx/Caddy 加 TLS，并设置 `RELAY_TOKEN`。
- 无障碍自动化无法保证 100% 成功；平台改版、风控、厂商杀后台都会影响。
- 本项目仅供个人设备学习研究，MIT “AS IS”，风险自负。
